# Catálogo con plantillas

Ejemplo de Express con archivos estáticos, vistas Handlebars y un parcial compartido para el pie de página. Ejecutá `npm run web` y abrí `http://127.0.0.1:3005`. Podés cambiar el saludo con `?nombre=Mauro`.

Usa datos ficticios y una interfaz propia. Complementa las referencias a Express, `hbs` y Handlebars proporcionadas junto con los ZIP de plantillas. No copia los builds de Angular/React ni presenta esas aplicaciones compiladas como código propio. No se configuró hosting ni se hizo un despliegue externo.

Se usa Handlebars directamente como motor de Express: la versión disponible de `hbs` presentaba una alerta de seguridad sin corrección publicada.
