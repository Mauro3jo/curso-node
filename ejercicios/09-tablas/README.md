# Tablas desde la terminal

Ejercicio de argumentos, validación y escritura de archivos con yargs y Node.

```sh
npm run tablas -- --base 5 --hasta 12 --listar
```

Guarda `data/tablas/tabla-5.txt`. `--salida` permite indicar otro archivo; si existe, se reemplaza. Base y cantidad de filas admiten enteros entre 1 y 1000.

Reconstrucción representativa del bloque de consola a partir de las referencias a yargs proporcionadas con los materiales. En la carpeta local no había un ZIP del proyecto de tablas original.
