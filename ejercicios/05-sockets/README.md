# Mensajes con sockets

Demostración de conexión, difusión de eventos y confirmaciones con Socket.IO. Ejecutá `npm run sockets` desde la raíz y abrí `http://127.0.0.1:3002` en dos pestañas.

Referencia: `curso-node-socket-server-basico-main.zip`. Los mensajes viven en memoria y desaparecen al recargar la página.
