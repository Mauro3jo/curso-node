# Fundamentos

`npm run fundamentos` muestra funciones, template strings y el orden de ejecución de temporizadores del ejemplo local `node-hola-mundo-0.1.0.zip`.

`npm run asincronia` recorre callbacks, promesas, destructuración y `async/await`, incluyendo un caso de error. Usa datos ficticios. Complementa el [ejemplo de bloqueo y callbacks de Klerith](https://github.com/Klerith/node-blocking-vs-non-blocking) que se proporcionó entre las referencias; no pretende reproducir sus tiempos de ejecución ni recuperar el código perdido.
