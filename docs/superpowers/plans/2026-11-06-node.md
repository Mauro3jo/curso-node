# Reconstrucción de aplicaciones Node

**Objetivo:** reconstruir los bloques funcionales identificados en `docs/alcance.md`, sin presentar los ZIP como código original recuperado.

**Arquitectura:** aplicaciones separadas en `ejercicios/`; turnos conserva su ubicación original. Una instalación npm en la raíz. Archivos locales ignorados por Git; bases de prueba aisladas y servicios escuchando solo en loopback.

**Stack:** Node 22+, Express, Socket.IO, Mongoose, JWT, bcrypt, TypeScript, Sequelize y MySQL/MariaDB.

**Especificación:** [inventario y límites](../../alcance.md).
